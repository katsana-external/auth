# Changelog for 7.x

This changelog references the relevant changes (bug and security fixes) done to `orchestra/auth`.

## 7.0.0

Released: TBD

### Changes

* Update support for Laravel Framework v10.
* Update minimum PHP requirement to ^8.1 (Laravel 10 requirement).
* Add forward compatibility for Laravel 8.x, 9.x, and 10.x.
* Update branch alias to 7.0-dev.

### Notes

* Orchestra dependencies (contracts, memory, support-core) remain at ^6.0 until Orchestra ecosystem releases Laravel 10 compatible versions.
* Full Laravel 10 compatibility will be available when Orchestra Platform releases compatible packages.
